# Thunderbolt 数值平衡系统 & Boss机制 重设计

## 概述

重新设计 thunderbolt.jsx 射击游戏的完整数值平衡系统和Boss机制，将难度从10级扩展到50级，每个难度等级有平滑的挑战曲线，并在每5级单位引入独特的Boss战。

---

## 一、数值平衡系统

### 1.1 难度等级

- 等级范围：1-50（原10级）
- 升级条件：每获得2000分提升1级
- 总分数上限：100,000分

### 1.2 HP成长曲线（二次曲线）

```
HP系数 = 1 + (等级-1) × 0.08 + (等级/50)² × 2
```

| 等级 | 系数 | elite HP (基础8) | 武器Lv3击杀时间 | 武器Lv5击杀时间 |
|------|------|------------------|----------------|----------------|
| 1 | 1.00 | 8 | 0.2s | 0.1s |
| 10 | 1.80 | 14 | 0.4s | 0.2s |
| 20 | 2.84 | 23 | 0.6s | 0.3s |
| 30 | 4.04 | 32 | 0.9s | 0.4s |
| 40 | 5.40 | 43 | 1.2s | 0.5s |
| 50 | 6.92 | 55 | 1.5s | 0.6s |

### 1.3 生成参数（1级→50级）

| 参数 | 1级 | 50级 | 曲线 |
|------|-----|------|------|
| 生成间隔 | 1500ms | 450ms | 线性递减 |
| 射击间隔 | 2200ms | 800ms | 线性递减 |
| 精英概率 | 3% | 20% | 线性递增 |
| 敌人速度倍率 | 1.0x | 2.0x | 线性递增 |

## 二、Boss系统框架

### 2.1 Boss出现规则

- Boss出现难度：5, 10, 15, 20, 25, 30, 35, 40, 45, 50
- 每个Boss只能被击败一次
- Boss素材：`src/assets/thunderbolt/boss/boss_1~10.png`

### 2.2 Boss战流程

1. **触发**：分数达到对应等级阈值且该Boss未被击败过
2. **进入**：清空所有敌机 → 停止生成普通敌机 → Boss从顶部出现
3. **战斗中**：Boss固定在Y≈80位置，水平正弦移动，不向下移动
4. **阶段切换**：HP降到60%和30%时切换，Boss闪烁+清空弹幕+短暂无敌(0.5s)
5. **击败**：掉落武器升级(W)+护盾(S)+回血(H)，难度等级+1
6. **恢复**：3秒后恢复正常敌人生成

### 2.3 Boss数据结构

```js
bossState: {
  active: false,
  boss: null,              // { level, hp, maxHp, x, y, width, height, speed, amplitude, moveTimer, phase, shootTimer, imageKey }
  phase: 1,
  phaseTransition: false,
  phaseTimer: 0,
  defeatedBosses: [],
  cleared: false,
}
```

### 3.1 Boss阶段切换效果

- 触发条件：Boss HP降到 maxHp×0.6 和 maxHp×0.3
- 视觉：Boss闪烁白色0.3秒
- 弹幕清理：清空场上所有Boss弹幕
- 无敌：0.5秒内不受伤害
- 提示文字："⚠ 阶段2" / "⚡ 阶段3"

### 3.2 Boss击败效果

- 爆炸动画：50+粒子大范围爆炸，持续1.5秒
- 掉落物：武器升级(W) + 护盾(S) + 回血(H)，向下掉落
- 等级跳级：难度等级+1
- 提示："🎉 Boss击败！难度+1"
- 3秒后恢复正常敌人生成

### 3.3 通关条件

击败第10个Boss（难度50）后：
- 清空屏幕，显示通关覆盖层
- 文字："🎉 恭喜通关！你击败了所有Boss！"
- 显示最终分数
- 提供"再玩一次"按钮

## 四、代码架构

### 4.1 改动范围

所有改动集中在 `src/page/games/thunderbolt.jsx` 单文件。

### 4.2 改动清单

| 区域 | 内容 |

### 4.3 Boss攻击函数（可复用）

| 函数 | 用途 |
|------|------|
| fireBossAimed(player) | 向玩家发射瞄准弹 |
| fireBossFan(n, spread, interval) | n路扇形散射 |
| fireBossCircle(n) | n向环形爆发 |
| fireBossSpiral(baseAngle, direction, bulletCount) | 螺旋弹 |
| fireBossWave(amplitude, frequency) | 正弦波浪弹 |
| fireBossLaser(angle) | 激光束 |
| fireBossTracking(n) | 追踪弹 |
| fireBossBoomerang(n) | 回旋弧线弹 |
| fireBossBurst(n, targetPlayer) | 连发弹 |
| fireBossWall() | 水平弹墙 |

### 4.4 关键设计原则

- 小怪1-3枪死：保持割草爽感
- 精英需要集火：提供战术决策
- 武器等级提升明显：玩家能感受到变强
- Boss战≠普通战节奏：Boss战期间不生成小怪
- 每个Boss攻击独特：10个Boss各不相同，每个3阶段递增
